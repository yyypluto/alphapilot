## 一、状态判断 (每日收盘后)

### 需要的指标

打开 TradingView，添加 QQQ 和 SOXX 两个日线图：

| 指标 | 计算方式 |
|------|----------|
| QQQ MA200 | QQQ 的 200 日简单移动平均线 |

| SOXX 60日回撤 | (当前价 - 近60日最高价) / 近60日最高价 |

### 为什么 SOXX 信号能解决 MA200 的假突破问题

> [!IMPORTANT]
> **Gemini 提到的 MA200 假突破绞肉机** — SOXX 背离信号可以在 QQQ 还没跌破 MA200 之前就提前切换到防守/避险，避免了在 MA200 附近反复穿插时的「左右挨打」。
>
> 10 年回测验证: SOXX 版最大回撤 **-22.2%** vs Simple 版 **-25.7%**，卡尔玛比率 **3.89 vs 2.99**，说明 SOXX 信号确实更早、更精准。

### 实操举例

```
场景 1: 2022 年初
  QQQ = $370, MA200 = $365, SOXX 60日回撤 = -12%, QQQ 60日回撤 = -3%

  判断: QQQ 在 MA200 之上 ✓, QQQ 回撤 > -4% ✓, 但 SOXX 回撤 < -10% ✗
  → 🔴 State 2: SOXX 已经崩了，QQQ 即将跟跌！立即撤退！
  (此时 Simple 版还停留在 State 0 继续持有 LEAPS，等它亏损)

场景 2: 正常牛市回调
  QQQ = $495, MA200 = $460, SOXX 60日回撤 = -3%, QQQ 60日回撤 = -2.5%

  判断: QQQ 在 MA200 上 ✓, QQQ 回撤 > -4% ✓, SOXX 回撤 > -5% ✓
  → 🟢 State 0: 正常回调，SOXX 也没走弱，继续进攻

场景 3: 半导体走弱但大盘还扛得住
  QQQ = $505, MA200 = $470, SOXX 60日回撤 = -7%, QQQ 60日回撤 = -1%

  判断: QQQ 在 MA200 上 ✓, QQQ 回撤 > -2% ✓, 但 SOXX 回撤 < -5% ✗
  → 🟡 State 1: 半导体在恶化，先转防守持正股
```

## 二、State 0 进攻模式: PMCC 操作细则

### 第一步: 买入 LEAPS Call (底仓)

| 参数 | 取值 | 说明 |
|------|------|------|
| 到期日 | **12 个月后** | 选距今 330-400 天的到期月 |
| Delta | **0.80** | 深度实值 |
| 资金 | 总资金 **70%** | 留 30% 管理短腿 |

**示例 (QQQ = $500):**
1. 期权链 → 到期 ≈ 2027 年 3 月 → Delta ≈ 0.80 的 Call → Strike **~$430**
2. 报价 ≈ $85/股 = **$8,500/合约**
3. $100k × 70% = $70,000 → 买入 **8 张** ($68,000)

### 第二步: 卖出 Short Call (收租)

| 参数 | 取值 |
|------|------|
| 到期日 | **30-45 天后** |
| Delta | **0.20** |
| 数量 | 与 LEAPS 张数 **相同** |

**示例:** Delta 0.20 → Strike **~$535** → 报价 ~$3.50 → 8 张共收 **$2,800**

### 短腿管理

| 情况 | 操作 |
|------|------|
| QQQ ≥ Short Strike × 99% | **立即买回**，等 5 天后重新卖更高的 |
| Short Call ≤ 3 DTE 且 OTM | 让它到期归零，赚全部权利金 |
| Short Call ≤ 3 DTE 且 ITM | 买回平仓，立即卖出下一期 |
| 其他 | 不操作 |

### LEAPS 滚动

| 条件 | 操作 |
|------|------|
| LEAPS 剩余 < 90 天 | 关闭 Short Call → 卖出 LEAPS → 买入新一年 LEAPS → 重开 Short Call |

> [!TIP]
> **应对 Gemini 提到的 LEAPS 流动性/滑点问题**：选择 LEAPS 时优先选流动性好的到期月（通常是 1 月和 6 月到期的 LEAPS），Open Interest > 500。下单用限价单(Limit)，不用市价单。

## 三、状态切换操作

> [!IMPORTANT]
> **应对「频繁切换摩擦」问题**: SOXX 信号的核心价值是让 State 0 ↔ State 1 的切换更少、更精准。只有当半导体也出问题时才离开进攻模式，正常的 QQQ 小幅震荡不会触发切换。

### 🟢→🟡 进攻 → 防守

**触发**: QQQ 回撤 < -4%，**或** QQQ 回撤 > -2% 但 SOXX 回撤 < -5%

```
次日开盘执行:
1. 买回所有 Short Call
2. 卖出所有 LEAPS Call (限价单，耐心挂中间价)
3. 用全部资金买入 QQQ 正股
```

### 🟢→🔴 进攻 → 避险

**触发**: QQQ 跌破 MA200，**或** QQQ 回撤 > -4% 但 SOXX 回撤 < -10%

```
次日开盘执行:
1. 买回所有 Short Call
2. 卖出所有 LEAPS Call
3. 用 20% 资金买入 GLD
4. 剩余 80% 持现金
5. 开启阶梯抄底 (见第四节)
```

### 🟡→🟢 防守 → 进攻

**触发**: QQQ 回撤恢复至 > -2%，**且** SOXX 回撤 > -5%

```
1. 卖出全部 QQQ 正股
2. 买入 LEAPS Call + 卖出 Short Call (全套)
```

## 四、State 2 避险模式: 阶梯抄底

**基础**: 20% GLD + 80% 现金，然后根据 QQQ 跌幅逐步买入：

| QQQ 60日回撤 | QQQ 仓位 | GLD | 现金 |
|-------------|----------|-----|------|
| 0% ~ -10% | 0% | 20% | 80% |
| -10% ~ -20% | **20%** | 20% | 60% |
| -20% ~ -30% | **50%** | 20% | 30% |
| > -30% | **80%** | 20% | 0% |

## 五、每日检查清单

```
□ 1. 查看 QQQ 收盘价 vs MA200
□ 2. 计算 QQQ 60 日回撤
□ 3. 计算 SOXX 60 日回撤          ← 关键新增
□ 4. 按决策树判断状态 (0/1/2)      ← 是否需要切换？
□ 5. 如果 State 0:
      □ LEAPS 剩余天数 < 90？      → 滚动
      □ Short Call 被击穿？         → 买回止损
      □ Short Call 到期？           → 重开新一期
□ 6. 如果 State 2:
      □ 回撤突破新档位？            → 加仓
```

## 六、风险控制铁律

> [!CAUTION]
> 1. **PMCC 仅在 State 0 使用** — 绝不在防守/避险模式开期权
> 2. **状态切换先关短腿后关长腿** — 避免裸空头风险
> 3. **盘后判断次日执行** — 不做盘中情绪交易
> 4. **Short Call 被击穿必须止损** — 买回后冷却 5 天再开新的
> 5. **LEAPS 选高流动性到期月** — 1月/6月档，OI > 500，限价单
> 6. **LEAPS 剩余 90 天就滚** — 不要拖，时间价值衰减加速

## 七、参数速查

| 参数 | 值 | 可调范围 | 说明 |
|------|-----|---------|------|
| LEAPS DTE | 365 天 | 330-400 | 更长 = 更贵更稳 |
| LEAPS Delta | 0.80 | 0.75-0.85 | 更高 = 跟涨更强 |
| Short Call DTE | 37 天 | 30-45 | Theta 甜蜜区 |
| Short Call Delta | 0.20 | 0.15-0.25 | 更低 = 安全 |
| LEAPS 滚动阈值 | 90 天 | 60-120 | 提早更安全 |
| MA 周期 | 200 日 | 不建议改 | 牛熊分界线 |
| 回撤窗口 | 60 日 | 40-80 | 信号灵敏度 |
| QQQ 防守阈值 | -4% | -3% ~ -5% | QQQ 自身回撤 |
| SOXX 预警阈值 | -5% | -4% ~ -6% | 半导体走弱 |
| SOXX 逃生阈值 | -10% | -8% ~ -12% | 硬件崩盘 |
